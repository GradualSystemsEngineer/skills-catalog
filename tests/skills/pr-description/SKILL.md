# Pull request description

1. Start with one sentence on why this change is needed.
2. Summarize what changed, grouped by area, in a short list.
3. Say how it was tested and what a reviewer should try by hand.
4. Call out risks, migrations, or follow-up work.
5. Keep it short enough to read in a minute.
